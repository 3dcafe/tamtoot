# TamToot 0.1.2

This update expands desktop development tools, improves AI agent workflows and Git integration, and reorganizes the interface.

## Desktop development

- Added Flutter SDK settings with connection testing and a device selector showing readable device names.
- Added Flutter Run, Debug, Stop, hot reload and hot restart using the debugger included in the SDK. The Debug panel provides breakpoints, stepping, call stacks and variable inspection.
- Added .NET SDK configuration, automatic discovery through environment variables and installation folders, and an SDK test button.
- Added .NET Run, Watch for hot reload, process output and Stop, including improved process termination on macOS. C# breakpoint debugging still requires a separate debug adapter.
- Added project detection for Flutter and C# / .NET. The launch toolbar displays the detected type and lets you select a project when several are found; unknown types are labelled explicitly.
- Added multi-root desktop workspaces. Additional folders appear in Solution and are accessible to AI agents through explicit folder prefixes.
- New and cloned desktop projects now use user-selected filesystem directories. Mobile projects continue to use application-managed storage.
- Moved macOS menus into the system menu bar while retaining shared commands across platforms.
- Disabled App Sandbox for macOS desktop builds so external SDK tools can run. These builds target distribution outside the Mac App Store.

## AI agents

- Added an Agent sidebar workflow, an AI STAR provider preset and local token management for saved profiles.
- Added persistent project conversations and project memory, allowing agents to retain useful findings across runs.
- Improved context selection, ranged and batched file reads, targeted edits, context compaction and token budgeting to reduce repeated investigation.
- Improved response recovery and agent completion behavior, including handling of interrupted runs and empty model responses.
- Expanded file attachments and platform drag-and-drop support, including Windows and macOS fixes. Attachment handling depends on the selected model API.
- Improved conversation history controls and Kanban task drag-and-drop.
- Removed the clean Git working-tree requirement for YOLO mode: agents can now start with uncommitted changes. Existing path checks, limits and approval behavior remain in place.

## Git and project files

- Added Razor highlighting for `.cshtml` / `.razor` and CSS highlighting, with templates available in the new-file dialog.

- Added file and folder creation from the Solution menu, with project-aware language defaults, language-package templates and editable file extensions.

- Improved compatibility with repositories used by native Git clients and added `.gitignore` handling.
- Expanded Git history with local and remote commits, commit details, changed files and before/after diffs.
- Improved pull and merge behavior, conflict reporting, and project refresh after Git operations.
- Added a workflow for initializing and pushing local projects to an empty GitHub repository, with optional repository creation.
- Reworked the Git changes panel with separate changed/unversioned groups, group selection, clearer indentation, smaller checkboxes and a compact commit-message field.
- Added image and SVG viewing in editor tabs.
- Added XML syntax highlighting for `.csproj`, `.xml`, MSBuild files, XAML and related formats.

## Interface

- Fixed HTTP method selector overflow and adapted the request URL / Send controls for narrow panels.

- Added clickable HEX color previews with a color picker, opacity controls and undoable code updates.

- Search results now reveal the matching line automatically when opening or switching files, including matches inside folded code.

- Renamed the menu entry to Settings and reorganized settings into selectable sections with a sidebar. Flutter and .NET are grouped under an expandable SDK section.
- Added a compact section selector for narrow screens.
- Made the active Solution, Git, Agent and Requests tab more visible with a background, underline and stronger text.
- Replaced green accents in the light theme with blue accents based on the TamToot logo.
- Restored the toolbar light/dark theme switch and made the displayed application version come from `pubspec.yaml`.
- Improved window titles, desktop folder access and HTTP Requests layout on smaller screens.

## Release tooling and documentation

- Improved signed Android build workflows and Windows build configuration.
- Added a manually triggered workflow to build a signed AAB and upload directly to Google Play production. It requires signing secrets and a Google Play service account; Google review and Managed publishing rules still apply.
- Expanded English and Russian documentation, store screenshots, contribution guidance and issue templates.

Desktop SDK features are available on Windows, Linux and macOS. Installed SDKs and any platform tools or project dependencies are still required.
