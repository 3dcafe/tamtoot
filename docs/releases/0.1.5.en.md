# TamToot 0.1.5

## Python, Kotlin and Java

- Added file recognition and syntax highlighting for Python (`.py`, `.pyw`, `.pyi`), Kotlin (`.kt`, `.kts`) and Java (`.java`).
- Added new-file templates for modules, classes, scripts and entry points.
- Highlight multiline strings, comments, annotations and common language constructs. Dedicated execution, debugging and semantic completion are not included.

## Git

- Reopening the Git tab and returning to the app reuse cached status instead of rescanning the repository.
- Removed periodic status scans. Saved edits and agent writes trigger batched checks; unsaved edits appear without scanning the disk.
- Added **Refresh** to the Git panel. Changes made outside TamToot can be checked manually.

## Agent privacy

- Added the optional **Enhance privacy** control; its selection is remembered.
- Start tasks without an automatic project file index, custom/project instructions or retained project memory.
- Mask recognizable domains and URL authorities before sending requests. Restore aliases locally when applying edits so real addresses remain intact.
- Read one small file excerpt at a time, up to 40 source lines. Search results provide locations rather than matching source text.
- Disable hooks and MCP in this mode and reject images, PDFs and other binary attachments before sending.

This mode reduces disclosure, but requested code/text excerpts still reach the selected provider. It is not complete anonymization or general secret detection.

Validation recorded for these changes: **346 tests passed, 1 skipped**, with clean static analysis. [Verification details](../verification.md).
