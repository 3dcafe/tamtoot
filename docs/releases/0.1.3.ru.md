# TamToot 0.1.3

Изменения проверены 4 октября 2026 года. Ниже отдельно указаны выполненные коммиты и дополнения, подготовленные в рабочем дереве.

## Изменения в коммитах

- Добавлены подсветка Markdown и живой предпросмотр рядом с исходным текстом, включая ссылки и изображения.
- Добавлена подсветка TypeScript для `.ts`, `.tsx`, `.mts` и `.cts`. Можно сворачивать блоки кода и многострочные шаблонные строки при работе с Angular-компонентами.
- Добавлена подсветка конфигурационных файлов, например `nginx.conf`.
- При открытии или клонировании другого проекта закрываются вкладки предыдущего проекта.
- Добавлено компактное контекстное меню Solution по правому клику и удержанию на мобильных устройствах: открытие, создание файла/папки, копирование путей, переименование, удаление, показ в файловом менеджере десктопа и действия Git.
- В меню Git добавлен пункт **Add to .gitignore**. Правило относится к выбранному пути и сохраняет содержимое файла. Уже отслеживаемые Git файлы остаются отслеживаемыми.
- Данные доступа после клонирования сохраняются локально и используются повторно для того же репозитория. Git-настройки сохраняются сразу, восстанавливают данные автора и содержат **Test repository access** — проверку прав чтения без скачивания репозитория. Данные хранятся в настройках приложения, вне проекта и `.tamtoot`; это локальные настройки, а не зашифрованное хранилище секретов.
- Исправлены замечания анализатора и обновлены тесты меню Git, SDK-настроек десктопа, языковых пакетов и лимитов исследования агента. Подсказка в поле ввода агента переведена на английский.

Исходные коммиты: [языки, Markdown и переключение проектов](https://github.com/3dcafe/tamtoot/commit/ca1f1ad), [gitignore и приватные Git-настройки](https://github.com/3dcafe/tamtoot/commit/e7b87de), [контекстное меню Solution](https://github.com/3dcafe/tamtoot/commit/8781881), [компактные меню](https://github.com/3dcafe/tamtoot/commit/0f42039), [обновление тестов](https://github.com/3dcafe/tamtoot/commit/da2d9d5), [исправление теста меню Git](https://github.com/3dcafe/tamtoot/commit/8dbd4ed).

Ранние коммиты этого дня также улучшили разделы настроек, поддержку XML/Razor/CSS, шаблоны файлов, палитру HEX-цветов, расположение элементов HTTP-запросов, оформление Git и публикацию в Google Play. Подробности того выпуска приведены в [заметках к 0.1.2](0.1.2.ru.md).

## Дополнения, подготовленные к следующему коммиту

- Добавлены подсветка SCSS-переменных, директив, комментариев и вложенных селекторов, а также шаблон нового файла.
- Angular определяется по `angular.json`; учитывается настроенный порт сервера разработки, по умолчанию `4200`.
- Интерактивный сайт можно закрепить рядом с редактором, изменить адрес, перезагрузить и закрыть. Заметный разделитель позволяет менять ширину; двойной клик делит область пополам. На узком экране редактор и предпросмотр располагаются вертикально.
- Сторонний Flutter WebView-пакет заменён собственными адаптерами в коде платформ: WebKit на macOS/iOS, Android WebView, WebView2 на Windows и WebKitGTK на Linux.
- Исправлена nullable-сигнатура метода кодека параметров платформенного представления Apple.

Предпросмотр подключается к уже запущенному серверу разработки и не запускает Angular. Успешная HTTP-проверка подтверждает доступность HTML-страницы, но не принадлежность сервера выбранному проекту. На телефоне укажите доступный адрес компьютера вместо его `localhost`.

На Windows требуется WebView2 Runtime. Для Linux нужны библиотеки разработки WebKitGTK 4.1 при сборке и соответствующие библиотеки при запуске. [Настройка и требования платформ](../angular-preview.md).

Проверки дополнений: прошли статический анализ Dart, проверка синтаксиса Swift и проверка plist Apple. Нативные сборки и проверка взаимодействия на всех платформах для этой версии рабочего дерева не выполнялись.
