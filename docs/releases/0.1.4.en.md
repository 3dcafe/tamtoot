# TamToot 0.1.4

## SSH, terminal and SFTP

- Added an SSH client with saved connection profiles, host-key verification and password or private-key authentication.
- Added an interactive remote terminal with keyboard input, resizing and ANSI/VT100 rendering.
- Added SFTP browsing, uploads, downloads, folder creation, renaming and deletion.
- Edit remote text files with conflict checks and retained recovery copies when replacing existing files.
- Added native Android and iOS file import/export. The SSH implementation introduces no additional library dependencies.
- Fixed the OpenSSH terminal integration test to support both Linux and macOS process monitors.

SSH → **Connect** → **Open terminal** or **Open SFTP**.

Windows/Linux builds and physical-device file-provider interaction still require verification. The native cryptography requires an independent audit. See [SSH/SFTP scope and limitations](../ssh-stage-5.ru.md) and [verification notes](../verification.md).
