# TamToot 0.1.5

## Python, Kotlin и Java

- Добавлены распознавание файлов и подсветка синтаксиса Python (`.py`, `.pyw`, `.pyi`), Kotlin (`.kt`, `.kts`) и Java (`.java`).
- Добавлены шаблоны новых файлов: модули, классы, скрипты и точки входа.
- Поддерживается подсветка многострочных строк, комментариев, аннотаций и основных конструкций языков. Отдельные запуск, отладка и семантическое автодополнение пока не добавлены.

## Git

- Повторное открытие вкладки Git и возврат в приложение используют сохранённый статус вместо нового сканирования репозитория.
- Убраны периодические проверки. Сохранённые правки и изменения агента запускают общую проверку; несохранённые правки отображаются без сканирования диска.
- Во вкладку Git добавлена кнопка **Refresh**. Внешние изменения файлов можно проверить вручную.

## Приватность агента

- Добавлена кнопка **Enhance privacy**; выбранный режим запоминается.
- Задача начинается без автоматического индекса файлов, пользовательских инструкций профиля, инструкций проекта и сохранённой памяти проекта.
- Распознаваемые домены и адресная часть URL маскируются перед отправкой запросов. При применении правок псевдонимы восстанавливаются локально, сохраняя реальные адреса.
- Агент читает по одному небольшому фрагменту, до 40 строк исходного кода. Поиск возвращает расположение совпадений вместо их содержимого.
- В этом режиме отключены hooks и MCP; изображения, PDF и другие бинарные вложения блокируются до отправки.

Режим уменьшает раскрытие данных, но выбранные фрагменты кода и текста всё равно отправляются провайдеру. Это не полная анонимизация и не универсальный поиск секретов.

Для этих изменений зафиксированы **346 прошедших тестов, 1 пропущенный** и чистый статический анализ. [Подробности проверок](../verification.md).
