# TamToot 0.1.3

Changes reviewed on October 4, 2026. These notes distinguish committed changes from additions currently prepared in the working tree.

## Committed changes

- Added Markdown syntax highlighting and a live source/preview split, including links and images.
- Added TypeScript highlighting for `.ts`, `.tsx`, `.mts` and `.cts`. Fold code blocks and multiline template literals while working on Angular components.
- Added highlighting for configuration files such as `nginx.conf`.
- Opening or cloning a different project closes the previous project's document tabs.
- Added compact Solution context menus for right-click and mobile long-press: open, create file/folder, copy paths, rename, delete, reveal in the desktop file manager and Git actions.
- Added **Add to .gitignore** to the Git file menu. Rules target the selected path and preserve existing content. Files already tracked by Git remain tracked.
- Save clone credentials locally and reuse them for the same remote. Git settings save immediately, restore author details and include **Test repository access**, which checks read access without downloading the repository. Credentials remain in application preferences, outside the project and `.tamtoot`; this is local preference storage, not an encrypted credential vault.
- Fixed analyzer findings and updated tests for Git menus, desktop SDK settings, language packages and agent investigation budgets. The Agent input placeholder is now in English.

Source: [language packages, Markdown and project switching](https://github.com/3dcafe/tamtoot/commit/ca1f1ad), [Git ignore rules and private Git settings](https://github.com/3dcafe/tamtoot/commit/e7b87de), [Solution context menu](https://github.com/3dcafe/tamtoot/commit/8781881), [compact menus](https://github.com/3dcafe/tamtoot/commit/0f42039), [test updates](https://github.com/3dcafe/tamtoot/commit/da2d9d5), [Git menu test fix](https://github.com/3dcafe/tamtoot/commit/8dbd4ed).

Earlier commits on the same day also improved settings navigation, XML/Razor/CSS support, file templates, the HEX color palette, HTTP request layouts, Git styling and Google Play publishing. See the [0.1.2 notes](0.1.2.en.md) for that release's details.

## Additional changes prepared for the next commit

- Added SCSS highlighting for variables, directives, comments and nested selectors, plus a new-file template.
- Detect Angular workspaces through `angular.json`, including configured development-server ports and a default of `4200`.
- Pin an interactive website preview beside the editor, edit its URL, reload it and close it. A visible draggable divider controls width; double-click splits the area evenly. Narrow layouts stack the editor and preview.
- Replaced the third-party Flutter WebView package with adapters implemented in TamToot's platform runners: WebKit on macOS/iOS, Android WebView, WebView2 on Windows and WebKitGTK on Linux.
- Fixed the nullable return signature of the Apple platform-view argument codec.

The preview connects to an already-running development server; it does not start Angular. A successful HTTP check confirms that an HTML page is available, not that the server belongs to the selected project. On mobile, enter the computer's reachable address rather than its `localhost`.

Windows requires WebView2 Runtime. Linux preview requires WebKitGTK 4.1 development libraries at build time and corresponding runtime libraries. [Setup and platform requirements](../angular-preview.md).

Validation of the additional changes: Dart static analysis, Swift syntax parsing and Apple property-list validation passed. Native builds and cross-platform interaction tests have not been run for this working-tree revision.
