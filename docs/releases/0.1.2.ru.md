# TamToot 0.1.2

Обновление расширяет инструменты разработки на десктопе, улучшает работу AI-агентов и Git и упорядочивает интерфейс.

## Разработка на десктопе

- Добавлены настройки Flutter SDK, проверка подключения и выбор устройства с понятными названиями.
- Добавлены запуск, отладка, остановка, hot reload и hot restart Flutter через отладчик из SDK. Панель Debug поддерживает точки останова, пошаговое выполнение, стек вызовов и просмотр переменных.
- Добавлены настройки .NET SDK, автоматический поиск через переменные окружения и каталоги установки, а также кнопка проверки SDK.
- Добавлены запуск .NET, Watch для горячего обновления, вывод процесса и остановка. Улучшено завершение процессов на macOS. Для отладки C# с точками останова по-прежнему нужен отдельный адаптер.
- Добавлено определение проектов Flutter и C# / .NET. Панель запуска показывает тип и позволяет выбрать проект, если найдено несколько. Неопределённый тип явно обозначается.
- Добавлены рабочие пространства с несколькими папками на десктопе. Дополнительные папки отображаются в Solution и доступны AI-агентам через явные префиксы.
- Создание и клонирование проектов на десктопе теперь используют выбранные пользователем каталоги файловой системы. На мобильных платформах сохраняется хранение внутри приложения.
- Меню macOS перенесено в системную строку меню с сохранением общих команд для всех платформ.
- В десктопных сборках macOS отключён App Sandbox для запуска внешних SDK. Такие сборки предназначены для распространения вне Mac App Store.

## AI-агенты

- Добавлены работа с агентом через боковую панель, профиль провайдера AI STAR и локальное управление токенами сохранённых профилей.
- Добавлены сохранение диалогов проекта и постоянная память проекта, позволяющая использовать результаты предыдущих запусков.
- Улучшены подбор контекста, чтение диапазонов строк и нескольких файлов, точечные правки, сжатие контекста и распределение токенов для сокращения повторного исследования.
- Улучшены восстановление после некорректных ответов и завершение задач, включая прерванные запуски и пустые ответы моделей.
- Расширена работа с вложениями и перетаскиванием файлов; исправлены проблемы на Windows и macOS. Поддержка типов вложений зависит от API выбранной модели.
- Улучшены управление историей диалогов и перетаскивание задач Kanban.
- Убрано требование чистого рабочего дерева Git для YOLO: агент может запускаться с незакоммиченными изменениями. Проверки путей, ограничения и правила подтверждения действий сохраняются.

## Git и файлы проекта

- Добавлена подсветка Razor для `.cshtml` / `.razor` и CSS, а также шаблоны этих форматов в окне создания файла.

- Добавлено создание файлов и папок из меню Solution с выбором языка по проекту, шаблонами из пакетов языков и редактируемым расширением файла.

- Улучшена совместимость с репозиториями, используемыми обычными Git-клиентами, и добавлена обработка `.gitignore`.
- Расширена история Git: локальные и удалённые коммиты, подробности коммитов, изменённые файлы и сравнение содержимого до и после правок.
- Улучшены pull и слияние, сообщения о конфликтах и обновление проекта после операций Git.
- Добавлена инициализация и отправка локального проекта в пустой репозиторий GitHub с возможностью создания репозитория.
- Переработана панель изменений Git: отдельные группы изменённых и неотслеживаемых файлов, выбор группы, более чёткие отступы, компактные чекбоксы и поле сообщения коммита.
- Добавлен просмотр изображений и SVG во вкладках редактора.
- Добавлена подсветка XML для `.csproj`, `.xml`, файлов MSBuild, XAML и связанных форматов.

## Интерфейс

- Добавлено контекстное меню Solution по правой кнопке мыши или удержанию: создание файлов и папок, открытие, копирование путей, показ в файловом менеджере, переименование и удаление файлов, действия Git.

- Исправлено переполнение списка HTTP-методов; поля URL и кнопка Send адаптированы к узким панелям.

- Добавлены цветовые образцы для HEX-кодов: палитра по нажатию, настройка прозрачности и замена кода с поддержкой отмены.

- Переход из поиска автоматически показывает найденную строку при открытии или переключении файла, включая совпадения внутри свёрнутого кода.

- Пункт меню переименован в Settings. Настройки разделены на разделы с навигацией слева; Flutter и .NET объединены в раскрывающийся раздел SDK.
- На узких экранах доступен компактный список выбора раздела.
- Активная вкладка Solution, Git, Agent или Requests теперь выделяется фоном, нижней линией и более заметным текстом.
- Зелёные акценты светлой темы заменены синими на основе логотипа TamToot.
- Возвращена кнопка переключения светлой и тёмной темы в панели инструментов. Версия приложения отображается из `pubspec.yaml`.
- Улучшены заголовки окон, доступ к папкам на десктопе и размещение HTTP Requests на небольших экранах.

## Подготовка релизов и документация

- Улучшены сборки подписанных Android-приложений и конфигурация сборки Windows.
- Добавлен workflow с ручным запуском для сборки подписанного AAB и отправки непосредственно в production Google Play. Нужны secrets подписи и сервисный аккаунт; проверка Google и правила Managed publishing сохраняются.
- Дополнены документация на английском и русском, скриншоты для магазинов, руководство для участников и шаблоны обращений.

Инструменты SDK доступны на Windows, Linux и macOS. Для работы нужны установленные SDK, необходимые платформенные инструменты и зависимости проекта.
