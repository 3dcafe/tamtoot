# TamToot 0.1.4

## SSH, терминал и SFTP

- Добавлен SSH-клиент с профилями подключения, проверкой ключа сервера и входом по паролю или приватному ключу.
- Добавлен интерактивный удалённый терминал с вводом с клавиатуры, изменением размера и отображением ANSI/VT100.
- Добавлены просмотр файлов по SFTP, загрузка и скачивание, создание папок, переименование и удаление.
- Удалённые текстовые файлы можно редактировать с проверкой конфликтов и сохранением резервных копий при замене существующих файлов.
- Добавлены нативные импорт и экспорт файлов на Android и iOS. Реализация SSH не добавляет сторонних библиотек.
- Исправлен интеграционный тест терминала OpenSSH для различий между системными мониторами Linux и macOS.

SSH → **Connect** → **Open terminal** или **Open SFTP**.

Сборки Windows/Linux и взаимодействие с файловыми провайдерами на физических устройствах ещё требуют проверки. Нативная криптография требует независимого аудита. [Возможности и ограничения SSH/SFTP](../ssh-stage-5.ru.md), [результаты проверок](../verification.md).
