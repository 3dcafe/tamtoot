# Документация Tamtoot на русском языке

Tamtoot — бесплатный редактор кода и обычного текста на Flutter для планшетов и настольных систем. В IDE есть собственный редактор, дерево проекта, вкладки документов, подсветка синтаксиса, поиск по проекту, встроенная работа с Git, HTTP-запросы и подключение локальных или облачных моделей.

## Возможности в текущей версии

- Редактирование кода и Markdown как обычного текста. Предпросмотр Markdown пока не реализован.
- Подсветка Dart, C#, HTML и JavaScript.
- Лёгкие контекстные подсказки для переменных, параметров, методов, полей, свойств и констант.
- Восстановление последнего проекта, открытых вкладок и несохранённых черновиков.
- Git Smart HTTP без системного исполняемого файла Git: clone, fetch, pull, push, история и создание коммитов.
- Проектные HTTP-запросы, которые можно хранить вместе с исходным кодом.
- Профили моделей, одиночные запросы и ограниченный инструментами агент для работы с проектом.

Tamtoot остаётся развивающейся основой IDE. Полный LSP, отладчик, PTY-терминал, исполняемые сторонние плагины и независимые группы редактора пока не реализованы.
