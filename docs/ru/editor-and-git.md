# Редактор, проекты и Git

[← Оглавление](README.md)

## Работа с проектом

Панель **Solution** показывает дерево текущего проекта. Нажатие на папку раскрывает её на месте, поэтому корень и соседние каталоги остаются видимыми. Название репозитория, ветку и путь можно увидеть при наведении на значок папки над деревом. Открытые документы находятся во вкладках центрального редактора.

Индикаторы файлов и папок:

- `●` — документ изменён в редакторе и ещё не сохранён;
- `M` — файл отличается от Git HEAD;
- `?` — новый файл, который Git ещё не отслеживает;
- `↑` — изменение находится в локальном коммите, которого нет в известной upstream-ветке.

Статус обновляется при открытии проекта, сохранении, возвращении приложения на передний план, вручную и каждые 30 секунд. Автоматический fetch или push не выполняется.

## Редактор и подсказки

Редактор поддерживает выбор текста, undo/redo, поиск и замену, мышь, сенсорный ввод и аппаратную клавиатуру. Программные лигатуры отключены: `!=`, `==`, `=>`, `>=` и `<=` отображаются отдельными символами именно так, как записаны в файле.

Через **File → Open file…** можно открыть отдельный файл с устройства и редактировать его без открытия проекта. На Android используется системный выбор документов: после предоставления доступа обычная команда **Save** записывает изменения в тот же файл.

Двойной щелчок мышью выделяет слово или имя метода целиком. Треугольник в поле номеров строк сворачивает и раскрывает тело класса или метода. В списке автодополнения `Tab` и `Enter` принимают выбранный вариант, стрелки меняют выбор, а `Escape` закрывает список.

Output показывает локальное время каждой записи. HTTP-запросы дополнительно выводят длительность выполнения. Весь журнал находится в одном выделяемом текстовом блоке, поэтому можно выделить и скопировать сразу несколько строк. Кнопка **Clear** очищает журнал.

Для Dart, C# и JavaScript ввод имени или точки после переменной открывает лёгкие проектные подсказки. Индекс находит локальные переменные, параметры, методы, поля, свойства и константы, показывает сигнатуру и соседний комментарий. Методы вставляются со скобками, значения — без скобок.

Это лексический индекс, а не компилятор и не LSP, поэтому сложный вывод типов и точная область видимости ограничены. Кеш хранится локально в `.tamtoot/cache/completions-v2.json`. Каталоги зависимостей и сборки не индексируются.

## Поиск по проекту

Откройте **Edit → Find in project** или нажмите `Ctrl+Shift+F` (`⌘Shift+F` на macOS). Результаты содержат путь, номер строки и фрагмент текста. Нажатие открывает документ и выделяет совпадение.

Поиск учитывает несохранённый текст открытых документов, умеет учитывать регистр, пропускает `.tamtoot`, зависимости, каталоги сборки, бинарные и слишком большие файлы. Максимум отображается 500 результатов.

## Сравнение и отмена изменений

Нажмите файл в списке изменений Git, чтобы открыть сравнение **HEAD → текущее содержимое**, включая несохранённый текст. Через правую кнопку мыши в Solution или Git, а на сенсорном экране через долгое нажатие, доступны **Compare with HEAD** и **Discard changes…**.

Отмена требует подтверждения. Отслеживаемый файл восстанавливается из последнего коммита, удалённый файл создаётся заново, а для нового неотслеживаемого файла предлагается удаление. Если HEAD или содержимое изменились после открытия сравнения, операция блокируется, чтобы не стереть более новые данные.

## Коммит и отправка

Откройте вкладку **Git** рядом с Solution.

1. Отметьте файлы, которые должны попасть в коммит. Выбранные несохранённые документы сначала записываются на диск.
2. Введите сообщение и нажмите **Commit**.
3. В меню с шестерёнкой укажите remote URL, имя и email автора, HTTPS-логин и токен. Токен хранится только в памяти открытой Git-панели.
4. Используйте компактные кнопки **Pull**, **Push** и **Sync**. Кнопка истории показывает локальные коммиты, авторов, даты и хеши.

**Pull** разрешён только для чистого рабочего дерева и выполняет fast-forward текущей ветки. Добавленные, изменённые и удалённые файлы перечисляются в Output. Расходящиеся истории нужно разрешать другим Git-клиентом: встроенный клиент не создаёт merge-коммиты.

**Push** отправляет уже созданные локальные коммиты и отклоняет non-fast-forward обновление. **Sync** сначала выполняет безопасный Pull и только после его успеха делает Push.

Выбор выполняется целыми файлами. Частичный staging, конфликты слияния, подпись коммитов, submodule, symlink-изменения и сложные индексы пока не поддерживаются.
