# SSH: этап 4 — удалённая PTY и терминал

Добавлен интерактивный терминал поверх существующего SSH-клиента. После входа в Settings → SSH → Connect нажмите **Open terminal**. Клиент открывает `session`, запрашивает `pty-req`, затем `shell`. Локальная оболочка или системный SSH приложению не требуются. Новых зависимостей в pubspec нет.

## Возможности

- Размер в символах определяется доступным экраном. Изменение окна, ориентации или доступной высоты передаётся серверу как `window-change` с задержкой 100 мс для объединения частых изменений. Диапазон — 2–300 столбцов и 2–120 строк; размеры в пикселях передаются как нули.
- Объявляется `TERM=vt100`: это консервативный контракт с terminfo. Помимо основных VT100-последовательностей реализованы распространённые ANSI-расширения: 16/256/RGB-цвета, курсор, SGR, очистка, вставка/удаление символов и строк, области прокрутки, origin/autowrap, табуляция, DEC line drawing, сохранение курсора и альтернативный экран.
- UTF-8 разбирается между SSH-пакетами. Повреждённые и неполные последовательности заменяются U+FFFD. Учитываются широкие CJK-символы, комбинируемые знаки, Hangul, пары regional indicators, emoji-модификаторы, ZWJ и VS16. Ширина неоднозначных символов — один столбец.
- История ограничена 2000 строками и 200000 ячейками, последовательность CSI — 128 символами, текст одной ячейки — 64 UTF-16 единицами. PTY не накапливает полный transcript и не имеет ограничения на суммарный вывод за время жизни канала. Окно приёма и очередь ввода сохраняют ограничения этапа 3.
- Аппаратная клавиатура: Enter, Backspace, Esc, Tab/Shift-Tab, стрелки, Home/End, Insert/Delete, Page Up/Down, F1–F12 и Ctrl/Alt. Стрелки учитывают application cursor mode; цифровая клавиатура — application keypad mode. `Ctrl+C` отправляет прерывание; `Ctrl+Shift+C` либо кнопка Copy копирует выделение/экран. Вставка — Ctrl+V, Ctrl+Shift+V, Cmd+V или кнопка Paste; Cmd+C копирует.
- Мобильная панель: Ctrl, Esc, Tab, стрелки, Enter, переключение экранной клавиатуры и History ↑/↓. Выделение — перетаскивание либо долгое нажатие с перемещением. Колесо мыши прокручивает историю; Return to live screen возвращает текущий экран.
- Вставка ограничена 64 КиБ и учитывает bracketed paste, если программа его включила. ESC и другие управляющие символы из буфера обмена удаляются; LF сохраняется внутри bracketed paste, иначе передаётся как CR. Обычные клавиши управления доступны отдельно. Многосимвольный ввод через IME также использует безопасную вставку; единичные обычные символы отправляются напрямую.
- Экран и ввод не сохраняются в проект, настройки, журналы или историю агента. OSC/DCS-последовательности, включая удалённое управление clipboard, игнорируются.

## Завершение и фон

Закрытие страницы закрывает терминальный канал, оставляя авторизованное соединение доступным в диалоге профиля. Кнопка Disconnect SSH session закрывает всё соединение. После выхода shell или обрыва отображается состояние, ввод отключается. Автоматическое повторное открытие shell и повтор команд отсутствуют.

На Android/iOS при переходе приложения в `paused` соединение явно закрывается. После возвращения пользователь видит сообщение о разрыве и переподключается сам. Это предсказуемая политика для текущего этапа: ОС не гарантирует непрерывную работу сокета в фоне. Временная потеря фокуса окна на desktop не закрывает соединение. Закрытие канала не гарантирует завершение всех запущенных удалённых процессов.

## Код и проверки

- `lib/core/ssh/channels/ssh_shell_channel.dart`: PTY, shell, resize; используются существующие окна, очередь stdin, EOF и закрытие канала.
- `lib/core/terminal/`: независимая от Flutter модель, UTF-8/ANSI-парсер и таблицы ширины Unicode 17.0.
- `lib/features/ssh_terminal_view.dart`: отрисовка через стандартный Flutter Canvas/TextPainter, клавиатура/IME, выделение, clipboard и lifecycle.
- `test/ssh_shell_protocol_test.dart`: порядок PTY → shell, отказ PTY/shell, неверные размеры, отмена, разрыв и более 2 МиБ потокового вывода.
- `test/terminal_screen_test.dart`: фрагментация, Unicode, цвета, перезапись широких ячеек, margins/origin, альтернативный экран, отчёты курсора, bounded scrollback и случайные входные данные.
- `test/ssh_terminal_widget_test.dart`: экран шириной 430 px, аппаратные/мобильные клавиши, копирование выделения, безопасная вставка, resize и уход/возврат из фона Android.
- Реальный изолированный OpenSSH: TERM, stty size, Unicode-ввод, Ctrl-C и выход shell; полноэкранный `vi` сохраняет временный файл после resize; интерактивный `top` обновляется, меняет размер и выходит по `q`. Системные программы здесь нужны только для независимого тестирования, приложение их не запускает.

Результаты общего набора тестов и сборок — в [verification.md](verification.md).

## Границы совместимости

Это реализация основного набора VT100/ANSI, а не полная эмуляция xterm. Не заявляются mouse reporting, изображения/Sixel, hyperlinks, все варианты расширенных клавиатурных протоколов, полный набор DEC-команд или поддержка любого terminal application. Базовые проверенные программы используют VT100 terminfo.

При resize сохраняется прямоугольная сетка, ограничиваются координаты и чинятся границы широких ячеек; автоматического reflow уже выведенных строк нет. Правый край текущего экрана при сужении обрезается. Полноэкранные программы перерисовывают экран по SIGWINCH. История хранится в исходной ширине. Для сложных письменностей и новых emoji внешний вид зависит также от шрифтов платформы; полная реализация Unicode grapheme segmentation не заявляется.

Windows/Linux и физические устройства требуют отдельной проверки. Функциональные тесты не заменяют независимый аудит собственной криптографии этапов 2–3.

## Воспроизведение

```sh
flutter analyze
flutter test
flutter build macos --debug
flutter build ios --simulator --debug
```

Таблицы Unicode генерируются стандартным Python, без сторонних пакетов:

```sh
python3 tools/generate_terminal_unicode.py
dart format lib/core/terminal/terminal_unicode.dart
```
