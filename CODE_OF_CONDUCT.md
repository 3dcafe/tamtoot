# Code of Conduct

## Our pledge

Tamtoot is an open project by **Latin Nikolay**. Everyone is welcome to use the
software, learn from it, fork it, and contribute improvements.

We pledge to make participation in this project a respectful experience for
everyone, regardless of age, body size, disability, ethnicity, sex
characteristics, gender identity and expression, experience level, education,
socio-economic status, nationality, personal appearance, race, religion, or
sexual identity and orientation.

## Expected behavior

- Be kind and constructive.
- Focus on what is best for the project and its users.
- Accept feedback gracefully.
- Credit others for their work.
- Respect that authorship of the original project remains with Latin Nikolay.

## Project principles

When you use Tamtoot or contribute to it, please follow these principles:

- **It should work everywhere.** That is the main goal: desktop, tablets, and
  the platforms Tamtoot already supports should stay usable. Prefer approaches
  that do not lock the product to one OS or one environment.
- **Think about backward compatibility.** Avoid breaking existing projects,
  settings, Git workflows, and saved data without a clear migration path.
  Preserve what users already rely on whenever you can.

Use the code freely, build on it, and **good luck with your projects**.

## Unacceptable behavior

- Harassment, insults, or personal attacks.
- Publishing others' private information without permission.
- Spam, trolling, or deliberately disruptive behavior.
- Anything that would be considered inappropriate in a professional setting.

## Enforcement

Report concerns by opening a GitHub issue marked as private if available, or by
contacting the maintainer through the repository. Maintainers may remove,
edit, or reject comments, commits, code, issues, and other contributions that
do not align with this Code of Conduct, and may temporarily or permanently ban
contributors for inappropriate behavior.
