Политика конфиденциальности Tamtoot

Tamtoot — бесплатная IDE и редактор кода, работающий преимущественно локально на устройстве пользователя.

Дата вступления в силу: 30 сентября 2026 года · Разработчик: 3dcafe / Latin Nikolay

РусскийEnglish
Кратко: разработчик Tamtoot не собирает и не продаёт персональные данные, не использует рекламу, аналитику, телеметрию или собственные серверы для обработки пользовательских файлов.

Какие данные обрабатывает приложение

Редактируемые файлы, проекты, настройки, история рабочих папок, HTTP-запросы и конфигурация инструментов сохраняются локально на устройстве либо в выбранной пользователем папке проекта. Разработчик Tamtoot не получает эти данные.

Tamtoot не создаёт пользовательские аккаунты и не запрашивает контакты, геолокацию, камеру, микрофон, идентификатор рекламы или полный доступ к хранилищу устройства.

Передача по инициативе пользователя

Сетевое соединение выполняется только при использовании функций, которые пользователь запускает сам: Git clone/fetch/pull/push, выполнение HTTP-запроса, обращение к выбранной модели или агенту, а также загрузка либо установка языкового пакета.

При таком действии выбранному пользователем сервису могут передаваться URL, учётные данные, содержимое запроса, выделенный текст, файл или иной явно выбранный контекст. Передача происходит напрямую между устройством и указанным сервисом. Обработка этих данных регулируется политикой соответствующего Git-хостинга, API, провайдера модели или другого сервиса.

Хранение и удаление

Локальные данные хранятся, пока пользователь не удалит их в приложении, в файловой системе либо не удалит само приложение и его данные средствами операционной системы. Проектные файлы могут оставаться в выбранной папке после удаления приложения. У разработчика нет копии этих данных и нет удалённого аккаунта, который требовал бы отдельного запроса на удаление.

Безопасность

Tamtoot не передаёт пользовательские данные на серверы разработчика. Для внешних подключений рекомендуется использовать HTTPS и доверенные сервисы. Пользователь самостоятельно определяет адрес назначения, содержимое запроса и предоставляемые внешнему сервису полномочия.

Дети

Приложение не предназначено специально для детей и сознательно не собирает данные детей или других пользователей.

Изменения политики

При изменении функций обработки данных эта страница будет обновлена, а новая дата вступления в силу будет указана выше.

Связь

Вопрос о конфиденциальности можно отправить через публичную систему обращений проекта. Не включайте в публичное обращение пароли, токены, приватные ключи или другие секреты.

Tamtoot Privacy Policy

Tamtoot is a free IDE and code editor that operates primarily on the user's device.

Effective date: September 30, 2026 · Developer: 3dcafe / Latin Nikolay

РусскийEnglish
Summary: the Tamtoot developer does not collect or sell personal data and does not use advertising, analytics, telemetry, or developer-operated servers to process user files.

Data handled by the app

Edited files, projects, settings, workspace history, HTTP requests, and tool configuration are stored locally on the device or in a project folder selected by the user. The Tamtoot developer does not receive this data.

Tamtoot does not create user accounts or request contacts, location, camera, microphone, advertising identifiers, or broad device-storage access.

User-initiated transfers

A network connection is made only when the user invokes a network feature, such as Git clone/fetch/pull/push, an HTTP request, a request to a selected model or agent, or downloading or installing a language package.

When the user takes such an action, the chosen service may receive a URL, credentials, request content, selected text, a file, or other context explicitly selected by the user. The transfer occurs directly between the device and the specified service. Processing by that service is governed by the privacy policy of the relevant Git host, API, model provider, or other service.

Retention and deletion

Local data remains until the user deletes it in the app or file system, or removes the app and its data through the operating system. Project files may remain in their selected folder after the app is removed. The developer has no copy of this data and provides no remote account that requires a separate deletion request.

Security

Tamtoot does not send user data to developer-operated servers. HTTPS and trusted services should be used for external connections. The user controls the destination, request contents, and permissions granted to an external service.

Children

The app is not directed specifically to children and does not knowingly collect data from children or other users.

Policy changes

If data-handling features change, this page will be updated and a new effective date will be shown above.

Contact

Privacy questions may be submitted through the project's public issue tracker. Do not include passwords, access tokens, private keys, or other secrets in a public issue.
