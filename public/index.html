Foundation 0.1

IDE в кармане и на столе

Flutter‑клиент для правок кода на iPad, Android и Windows: свой редактор, панели, команды и клон репозиториев по HTTPS — без системного git.

Открыть на GitVerse Скачать APK / Windows

Что уже есть

  • Редактор с подсветкой Dart и C#, поиск и замена
  • Docking‑панели, темы, горячие клавиши, восстановление сессии
  • Clone / open project по Smart HTTP (GitVerse и другие HTTPS)
  • Ручные CI‑сборки: Android APK и Windows zip

Где работает

  • iOS / iPadOS — правки в песочнице приложения
  • Android — документы через системный picker
  • Windows / macOS / Linux — обычные файлы и папки
  • Web — ограниченно (CORS у git‑хостов)

Пока не в 0.1

  • LSP, компиляторы, отладчик, терминал PTY
  • SSH, marketplace, совместная работа
  • Полный push‑flow на всех платформах ещё дорабатывается

Как взять сборку

В репозитории Actions: вручную запускаете Build Android APK или Build Windows exe, скачиваете артефакт. Windows — это zip с tamtoot.exe и DLL рядом.
