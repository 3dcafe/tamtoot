# Security Policy

## Supported versions

Security fixes are applied to the current `main` branch of Tamtoot.

## Reporting a vulnerability

Please **do not** open a public issue for security problems that could harm
users (credential leaks, remote code execution, unsafe defaults that expose
tokens, and similar).

Instead:

1. Prefer GitHub's private vulnerability reporting for this repository, if
   enabled.
2. Or open a minimal private contact path via the repository maintainer
   (**Latin Nikolay** / `3dcafe`) describing the impact without a full exploit.

Include:

- Affected platform (macOS, Windows, Android, web, …)
- Tamtoot / commit version if known
- Steps to reproduce
- Whether credentials or user data can be exposed

You should receive an acknowledgement when the report is seen. Please give a
reasonable time to investigate before any public disclosure.

## Non-security bugs

Ordinary bugs and UX issues belong in public GitHub issues using the templates.
